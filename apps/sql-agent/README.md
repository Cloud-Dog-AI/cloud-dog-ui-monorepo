# SQL Agent UI App

`apps/sql-agent` is the React Web UI for `sql-agent-mcp-server`.

## Commands

```bash
npm run dev --workspace @cloud-dog/app-sql-agent
npm run typecheck --workspace @cloud-dog/app-sql-agent
npm run build --workspace @cloud-dog/app-sql-agent
npm run lint --workspace @cloud-dog/app-sql-agent
npm run e2e --workspace @cloud-dog/app-sql-agent
npm run a11y --workspace @cloud-dog/app-sql-agent
```
