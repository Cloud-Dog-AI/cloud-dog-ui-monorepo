# @cloud-dog/app-git-mcp

Web UI for `git-mcp-server` using `@cloud-dog/*` packages only.

## Commands

- `npm run dev -- --filter=@cloud-dog/app-git-mcp`
- `npm run lint -- --filter=@cloud-dog/app-git-mcp`
- `npm run typecheck -- --filter=@cloud-dog/app-git-mcp`
- `npm run e2e -- --filter=@cloud-dog/app-git-mcp`
- `npm run a11y -- --filter=@cloud-dog/app-git-mcp`
