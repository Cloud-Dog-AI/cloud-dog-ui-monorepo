# Index Retriever UI App

`apps/index-retriever` is the React Web UI for `index-retriever-mcp-server`.

## Commands

```bash
npm run dev --workspace @cloud-dog/app-index-retriever
npm run typecheck --workspace @cloud-dog/app-index-retriever
npm run build --workspace @cloud-dog/app-index-retriever
npm run lint --workspace @cloud-dog/app-index-retriever
npm run e2e --workspace @cloud-dog/app-index-retriever
npm run a11y --workspace @cloud-dog/app-index-retriever
```
