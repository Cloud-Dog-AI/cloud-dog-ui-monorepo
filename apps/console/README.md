# Console UI App

`apps/console` is the internal diagnostics and verification console for Cloud-Dog frontend package integration.

## Commands

```bash
npm run dev --workspace @cloud-dog/app-console
npm run typecheck --workspace @cloud-dog/app-console
npm run build --workspace @cloud-dog/app-console
npm run lint --workspace @cloud-dog/app-console
npm run e2e --workspace @cloud-dog/app-console
npm run a11y --workspace @cloud-dog/app-console
```
