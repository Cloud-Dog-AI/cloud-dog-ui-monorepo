# Expert Agent UI App

`apps/expert-agent` is the React Web UI for `expert-agent-mcp-server`.

## Commands

```bash
npm run dev --workspace @cloud-dog/app-expert-agent
npm run typecheck --workspace @cloud-dog/app-expert-agent
npm run build --workspace @cloud-dog/app-expert-agent
npm run lint --workspace @cloud-dog/app-expert-agent
npm run e2e --workspace @cloud-dog/app-expert-agent
npm run a11y --workspace @cloud-dog/app-expert-agent
```
