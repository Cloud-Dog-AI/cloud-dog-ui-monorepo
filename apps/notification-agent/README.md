# Notification Agent UI App

`apps/notification-agent` is the React Web UI for `notification-agent-mcp-server`.

## Commands

```bash
npm run dev --workspace @cloud-dog/app-notification-agent
npm run typecheck --workspace @cloud-dog/app-notification-agent
npm run build --workspace @cloud-dog/app-notification-agent
npm run lint --workspace @cloud-dog/app-notification-agent
npm run e2e --workspace @cloud-dog/app-notification-agent
npm run a11y --workspace @cloud-dog/app-notification-agent
```
